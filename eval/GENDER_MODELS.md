# Gender classifier comparison (speech vs non-verbal)

Generated by `eval/compare_gender_models.py` from features extracted by `eval/extract_features.py`.
All numbers are on **test speakers only** (speaker-disjoint from every trained head, see `eval/splits.json`). Items: each test clip appears twice, as the (≤3 s) full clip and as one random 0.25-1.5 s crop. Threshold 0.5 on calibrated p(female). bacc = balanced accuracy, ECE = expected calibration error (10 bins, %). See `eval/DATA.md` for the data and its gaps.

## Models that could not be evaluated here

Hugging Face file downloads are blocked on this build machine (the CDN host `us.aws.cdn.hf.co` is refused by the network proxy; adding it was declined), so these requested candidates were **not** evaluated: `JaesungHuh/voice-gender-classifier` (weights only on HF / Google Drive), `audeering/wav2vec2-large-robust-24-ft-age-gender` (+6-layer), `alefiury/wav2vec2-large-xlsr-53-gender-recognition-librispeech`, and `speechbrain/spkrec-ecapa-voxceleb` embeddings. Substitutes: the ECAPA-TDNN of TaoRuijie/ECAPA-TDNN (GitHub, MIT; VoxCeleb2-trained, 192-d, the same backbone JaesungHuh fine-tuned) and WavLM Base+ from torchaudio (download.pytorch.org).
